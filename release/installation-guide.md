# Installation Guide

## Windows (Portable)

Dastra is distributed as a portable ZIP file for Windows, requiring no administrative privileges or installation.

1. Download `Dastra-v1.0.0-rc.1-Windows-Portable.zip`.
2. Extract the contents to a folder where you have read/write permissions (e.g., your Desktop, Documents, or a USB Drive). *Do not extract to `C:\Program Files\` as Windows restricts write permissions.*
3. Double-click `dastra.exe` to launch.
4. **Note**: Dastra operates locally. It will create a `data/` folder next to the executable to store its database and settings.

## Android (APK)

1. Download `Dastra-v1.0.0-rc.1-Android.apk` to your device.
2. Open the file manager and tap the APK to install.
3. If prompted, you may need to enable "Install unknown apps" for your browser or file manager in Android Settings.
4. Once installed, Dastra will appear in your app drawer. Ensure you grant storage permissions when prompted so Dastra can read and write files.
