# Release v1.0.0-rc.1: First Official Release Candidate

🚀 **Dastra v1.0 RC1 is now available!** 🚀

This release marks the culmination of our core development phase. The application architecture has stabilized, the Material 3 UI is highly polished, and our core offline capabilities are robust.

## What's New
* **Dynamic Workspace**: Track all your file conversions in a centralized, searchable history database.
* **Tool Catalog**: A beautifully organized Dashboard providing access to Document, Image, and Security tools.
* **Portable Windows Build**: Run Dastra straight from a USB drive without installation.
* **Android APK**: Native mobile experience with adaptive layouts.

## Downloads
* `Dastra-v1.0.0-rc.1-Windows-Portable.zip` (Requires Windows 10/11 x64)
* `Dastra-v1.0.0-rc.1-Android.apk` (Requires Android 8.0+)

## ⚠️ Important Note
This is a Release Candidate. While we believe the core features are stable, you may encounter edge cases with very large PDF files or specific Android permissions. Please review the `known-issues.md` file.

Happy offline converting!
