# Frequently Asked Questions

## Is Dastra really 100% offline?
Yes. Dastra does not include any telemetry, crash reporting, or cloud APIs. Everything from PDF conversion to image compression is processed entirely on your local CPU.

## Will there be an iOS or Mac version?
Dastra's UI is already compatible with iOS and macOS (built on Flutter). We plan to distribute Universal macOS binaries in a future release once the native Desktop Runtimes are compiled for Apple Silicon.

## Where are my files saved?
By default, Dastra outputs processed files to the same directory as the original input file, appending `_dastra` to the filename. You can change this behavior in the Settings.

## Is it free?
Dastra v1.0 is free and open-source under the terms specified in the `LICENSE` file.
