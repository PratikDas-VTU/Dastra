# Changelog

All notable changes to Dastra will be documented in this file.

## [1.0.0-rc.1] - 2026-07-28
### Added
- First official production release candidate (v1.0 RC1).
- Offline PDF processing, conversion, merging, and compression.
- Secure offline credential generation and strength auditing.
- Local SQLite workspace history tracking.
- Cross-platform desktop (Windows COM/Python/LibreOffice) and portable mode capabilities.
- Repository structure cleaned and standardized for production release.
