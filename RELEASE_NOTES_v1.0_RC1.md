# Dastra v1.0 Release Candidate 1

We are thrilled to announce the first Release Candidate for Dastra v1.0! 

Dastra is designed to be your ultimate offline productivity companion. In a world increasingly reliant on cloud services, Dastra guarantees that your sensitive documents, images, and credentials never leave your machine.

## Feature Highlights

- **Universal UI Architecture**: A beautiful, Material 3-powered adaptive interface that feels at home on Desktop and Mobile.
- **Offline Document Processing**: Convert PDFs to Word, merge documents, split pages, and compress files locally.
- **Offline Image Compression**: Reduce file sizes drastically while maintaining quality, without uploading to web services.
- **Security Tools**: Generate highly secure passwords and evaluate their strength locally.
- **Productivity Workspace**: Keep track of your recent conversions and files with an integrated, searchable SQLite history.
- **Zero Telemetry**: No tracking, no ads, no cloud.

Please test this release and report any issues before the final v1.0 stable release.
