# Dastra Roadmap

This document outlines the current status and future vision for Dastra. As a privacy-first, offline productivity suite, our goal is to continuously expand local processing capabilities without compromising security or speed.

## Current Release: v1.0.0 (The Foundation)
- [x] Universal Desktop & Mobile UI Architecture
- [x] Dual-Edition Release Automation (Community vs Developer)
- [x] Native Windows Installer Architecture (Inno Setup)
- [x] Segregated `LOCALAPPDATA` Data Storage
- [x] Offline Document Processing (PDF Merging, Splitting, Compression, Conversion)
- [x] Offline Image Compression
- [x] Offline Password Generation & Strength Evaluation
- [x] Local SQLite Workspace History Tracking
- [x] Material 3 Adaptive Design System
- [x] Android Mobile Support

## Next Steps: v1.1 (Performance & Extensibility)
- [ ] Plugin API for Community Tools
- [ ] Video Processing Tools (FFmpeg integration)
- [ ] Audio Extraction & Conversion
- [ ] OCR Capabilities (Tesseract integration)
- [ ] Advanced Workspace Search (Full-text search)

## Future Vision: v2.0 (The Ultimate Offline Hub)
- [ ] Native macOS (Universal Binary) & Linux AppImage Distribution
- [ ] Local AI capabilities (Small Language Models via ONNX/llama.cpp)
- [ ] Peer-to-Peer encrypted sharing between local devices
- [ ] Comprehensive Developer Tools (JSON formatting, Base64, Hashing)
- [ ] Bulk automation workflows

*Note: The roadmap is subject to change based on community feedback and technological constraints.*
